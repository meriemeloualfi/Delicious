## Getting Started

### Prerequisites

- A modern web browser
- Node.js and npm (to install Bootstrap and Bootstrap Icons)

### Installation

```bash
git clone https://github.com/meriemeloualfi/Delicious.git
cd Delicious
npm install
```

### Run the website

Open `index.html` in your browser, or use the **Live Server** extension in VS Code
(right-click on `index.html`, then **Open with Live Server**).

### Compile the Sass files (if needed)

```bash
npx sass src/sass/[main.scss] [output.css] --watch
```
